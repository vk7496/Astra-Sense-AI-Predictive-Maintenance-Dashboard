AstraSense™ – Real-Time Industrial Predictive Maintenance (AI + IoT Demo)

AstraSense™ is a lightweight AI-powered predictive maintenance system designed for industrial equipment such as pumps, motors, compressors, and HVAC units.
This demo simulates real sensor data (vibration, temperature, FFT spectrum) and uses machine-learning–based anomaly detection to predict early-stage failures such as bearing damage, imbalance, misalignment, and overheating.

🔧Key Features

Real-time sensor simulation (vibration, temperature, FFT)

AI-generated anomaly detection & risk scoring

Early warning insights (bearing outer-race fault scenario)

Clean industrial dashboard built with Streamlit

Modular architecture – ready for integration with real IoT sensors (Modbus, MQTT, OPC-UA)

Suitable for POC / pilot projects in oil & gas, water utilities, manufacturing, and smart facilities
